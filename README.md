# ⚙️ ESC | Automação Industrial

Site institucional desenvolvido para a **ESC Manutenção e Automação Industrial**, empresa especializada em soluções para automação, manutenção e segurança de máquinas e equipamentos industriais.

## 🌐 Sobre o projeto

O objetivo deste projeto é apresentar os serviços, projetos e soluções oferecidos pela ESC de forma moderna, profissional e responsiva.

O site foi desenvolvido pensando tanto na experiência em computadores quanto em dispositivos móveis.

## 🛠️ Principais serviços apresentados

- Automação Industrial
- Manutenção Industrial
- Adequação de máquinas conforme NR-12
- Desenvolvimento de máquinas e equipamentos
- Painéis elétricos
- Projetos e modelagem
- Soluções personalizadas para processos industriais

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## ✨ Funcionalidades

- Layout responsivo
- Navegação por seções
- Galeria de projetos
- Apresentação dos serviços da empresa
- Formulário de contato/orçamento
- Integração com WhatsApp
- Integração com Instagram
- Animações e efeitos de interação
- Página de links para redes sociais

## 📱 Responsividade

O site possui adaptações para diferentes tamanhos de tela, incluindo:

- Desktop
- Tablets
- Smartphones
- Navegadores mobile
