# ⚙️ ESC | Automação Industrial

Site institucional desenvolvido para a **ESC Manutenção e Automação Industrial**, empresa especializada em soluções para automação, manutenção e segurança de máquinas e equipamentos industriais.

## 🌐 Sobre o projeto

O objetivo deste projeto é apresentar os serviços, projetos e soluções oferecidos pela ESC de forma moderna, profissional e responsiva.

O site foi desenvolvido pensando tanto na experiência em computadores quanto em dispositivos móveis, com foco em organização visual, facilidade de navegação e apresentação clara dos serviços da empresa.

## 🖥️ Preview

O projeto apresenta uma interface moderna baseada na identidade visual da ESC, utilizando tons de azul, dourado e branco.

Entre as principais áreas do site estão:

- Serviços
- Projetos realizados
- Painéis elétricos
- Desenvolvimento de máquinas e equipamentos
- Projetos e modelagem 3D
- Adequação NR-12
- Conteúdo técnico
- Formulário para solicitação de orçamento
- Contato e redes sociais

## 🛠️ Principais serviços apresentados
